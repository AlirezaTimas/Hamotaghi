## تبدیل به PDF

برای تبدیل فایل‌های Markdown به PDF، از یکی از روش‌های زیر استفاده کنید:

### روش 1: Pandoc (پیشنهادی)

```bash
# نصب Pandoc
# Windows: choco install pandoc
# Mac: brew install pandoc

# تبدیل به PDF
pandoc documentation/01_View_Details_and_Send_Request.md \
  -o documentation/01_View_Details_and_Send_Request.pdf \
  --pdf-engine=xelatex \
  -V mainfont="Tahoma" \
  -V dir=rtl
```

### روش 2: VS Code Extension

1. نصب extension "Markdown PDF"
2. باز کردن فایل Markdown
3. کلیک راست → "Markdown PDF: Export (pdf)"

### روش 3: ابزارهای آنلاین

- [Markdown to PDF](https://www.markdowntopdf.com/)
- [Dillinger](https://dillinger.io/)
